## 0. 结论摘要（四句话）

1. **时序**：新段插在 10 文档 §2 的 **第 4 步 `acceptSummons` 与第 5 步 `recruitInteract` 之间**，
   共 5 个新步骤（符水 → 铜钱剑 → 诬告 → 追杀 → 被迫反）。**征兵与举事全部后移**，
   举事仍在征兵之后（先有兵、才立营）。
2. **因果可见**：符水与铜钱剑各自留下**计数事实**；诬告对话**逐条引用玩家实际做过的事**
   （按数值分档拼台词），让玩家一眼看出"我做的都是合法善事，却被当成造反证据"。
3. **两件道具都不破坏经济**：铜钱剑首版是**剧情象征物**（不可装备、不可交易、不量产），
   后置才在铁匠铺转为可造装备；符水是**粥棚交互动作**，消耗剧情资源「符灰」（张角每日供给、
   有硬上限），不消耗粮草、不产出任何可卖物品。
4. **追杀可战可逃**：不走必败演出。打 → 杀官兵、官府定反（举事动机最强、围剿来势更凶）；
   逃 → 官兵焚村、张角退无可退（举事台词不同、围剿稍缓）。两条路都通向反抗，不设"逃了就断链"。

## 3. 合法 → 被诬的因果表达

### 3.1 两件善事怎么留痕

| 善事 | 留痕键 | 写入点 | 玩家可见反馈 |
|---|---|---|---|
| 散符水 | `story.s02.boonWater.count`（0~50） | N1 每次交互 +1 | 每碗一条 showTip；粥棚上方计数「已施 X 碗」 |
| 受惠村民 | `story.s02.boonWater.beneficiaries`（= count，村民实体 id 列表另存 `story.s02.boonWater.servedIds`） | 同上 | 喝过符水的村民换「精神」表情/站立姿态（表现层可选） |
| 发铜钱剑 | `story.s02.coinSword.given`（0~7）/ `.forged`（=7） | N2 每次 +1 | 村民把剑挂在腰上（附件层）；提示「你把一柄铜钱剑交到 X 手里」 |
| 聚众人数 | `story.s02.crowd.count`（复用施粥/招募队列的在场村民数） | 场景扫描写入 | 县尉台词直接引用「二百余人聚在粥棚前」 |

### 3.2 诬告由谁触发、依据什么

- **谁**：县尉（`enemy.s02_xianwei`）——县廷的执行者，不是州郡大员；后续围剿才是郡兵
  （层级差让"小官先来灭口"合理）。
- **何时**：N3 的触发门槛 `coinSword.given >= 3` **或** `boonWater.count >= 20`（先到者触发）。
  门槛设计意图：玩家**必须先做够善事**才会招来诬告——因果关系由玩家自己的行为驱动，
  不是定时脚本。
- **依据**（证据数组 `story.s02.accusation.evidence`）：由事务按当时的黑板实际值组装：

| 证据条目 | 生成条件 | 县尉台词（分档） |
|---|---|---|
| `crowd` | `story.s02.crowd.count >= 50` | 「聚众二百余口，昼夜不散——这是要做什么？」 |
| `boonWater` | `boonWater.count >= 20` | 「以符水惑众，称能治疫——妖言也。」 |
| `coinSword` | `coinSword.given >= 3` | 「私铸兵刃，遍授村夫——这是要反。」 |
| `offering` | `story.s02.porridge.laid` | 「散粮收买人心，钱粮从何而来？」 |

- **对照写法（让玩家看出"合法却被告成造反"）**：每念一条罪状，紧接着一句**玩家视角的
  合法解释**（内心独白或旁白），例如：
  - 县尉：「以符水惑众。」→ 旁白：「你只是把熬好的药汤递给咳血的孩子。」
  - 县尉：「私铸兵刃。」→ 旁白：「那铜钱剑是给村民防野兽的，刃口钝得切不开皮。」
  - **这一"罪名 / 事实"并置是整段的核心表达**，必须逐条成对出现，不能只念罪状。

### 3.3 数据契约（本段新增）

| 类型 | 名字 | 说明 |
|---|---|---|
| 事实 | `story.s02.boonWater.count` / `.stock` / `.servedIds` | 施符水计数 / 剩余符灰 / 受惠村民实体 |
| 事实 | `story.s02.coinSword.given` / `.forged` | 发出数量 / 铸造总量（7） |
| 事实 | `story.s02.crowd.count` | 粥棚前在场村民数（诬告台词引用） |
| 事实 | `story.s02.accused` / `.accusation.evidence` | 诬告成立 / 证据条目数组 |

## 4. 铜钱剑

### 4.1 首版定位：剧情象征物（不可装备）

| 项 | 取值 |
|---|---|
| 物品 id | `item.s02.coin_sword` |
| 名称 / 描述 | 铜钱剑 ·「一串铜钱缠成的小剑，剑身刻着太平二字，刃口钝得切不开皮。」 |
| `type` | `quest`（剧情物品，不进交易/掉落池） |
| `equipment` | **false**（不可装备；刻意如此——它不是武器，是"被当成武器"的物证） |
| `stackable` / `maxStack` | true / 99（每个村民 1 把，玩家手里只是过手） |
| `sellPrice` | 0（不可卖，防刷钱） |
| 属性 | 无（`stats` 留空） |
| 来源 | **不可量产**：仅 N2 按张角预铸的 7 把发放，发完即止 |
| 玩家是否保留 | 否——**全部发给村民**；玩家背包不持有（`boundToNpc:true`） |

> 为什么不做成装备：若首版就能装备，玩家会为了属性去刷（虽然只有 7 把），
> 也会让"官府诬你私铸兵刃"变成事实而非构陷——**必须钝、必须不能打**，诬告才成立。

### 4.2 后续转化（后置，S03+）

| 项 | 设计 |
|---|---|
| 转化条件 | 举事后铁匠铺落成（`construction.s02.smithy`）+ 事实 `story.s02.uprising` + 解锁事实 `story.s02.coinSword.desecrated`（村民的剑被官兵收走/折断，张角决定"既然说我们铸兵，那就真铸"） |

## 5. 符水

### 5.1 定位：粥棚交互动作（不是技能、不是可携带消耗品）

| 项 | 取值 |
|---|---|
| 形态 | **场景交互点**：`placement` `S02-prop-boonWater`（粥棚旁的陶瓮/药炉，`worldProp: true` + 交互服务） |
| 动作 | 玩家走近按交互键 → 消耗 1 份「符灰」→ 该村民喝下 → 计数 +1 |
| 资源 | `story.s02.boonWater.stock`（符灰库存），**张角每日供给**：进场 `stock = 20`，每过一夜 +20，**总上限 50** |
| 硬上限 | `boonWater.count` 封顶 **50**（对应"200 村民里 50 人受惠"的叙事口径，不是全救） |
| 产出 | **不产出任何物品/货币/经验**；不给 buff（`heal` 只做表现，不回血） |
| 消耗 | 不消耗 `food`、不消耗铜钱——**与粮草/经济完全解耦**（见 §8.4） |

### 5.2 为什么这样设计（不破坏后续节奏）

1. **有上限**：符灰是剧情资源、每日供给、总量 50 —— 玩家无法靠刷符水获得任何东西。
2. **不产资源**：只写一个计数事实，不进背包、不进交易、不进掉落池。
3. **不碰粮草**：09 文档的日结粮耗只算"士兵/人口"，符水不在其中（§8.4）。
4. **与"赈济"区分**：07 §3.3 的「主动赈济 +5 民心」是**城池级、耗 food、每日 1 次**；
   符水是**村庄级、不耗 food、有总上限**，两者不共用账本（S02 无城池，本段也不写 `cityStates`）。

### 5.3 表现（首版最小）

- 陶瓮 glow（复用 `LightGlowRenderer`，暖黄 `breathe`）；
- 每次施与：一碗白气 + 村民鞠躬（2 帧序列帧即可，允许后置）；

| **节奏停顿**（安静→冲突→昏迷→救援） | 新主线是"善举→诬告→追杀→反抗"的连续上升，8 步乞讨链让首段**支线感过强、主线推进慢** |
| **昏迷用一次** | 新段追杀还可能再用（§6.4），三次昏迷会让"昏倒"变成廉价手段 |

**结论**：乞讨链的**功能大部分已被新主线覆盖或反向冲突**；但"昏迷→张角救援→杀/救抉择"是两人关系的**基石**，不能连带删除——所以真正要评估的是"**用什么事件把主角打倒**"，而不是"要不要保留乞讨"。

### 12.3 三套方案

#### 方案一：保留但重写（乞讨 → 争粥秩序冲突；打晕 → 被捕出口）

| 项 | 内容 |
|---|---|
| 改动 | ①乞讨对话改为**争粥**（张角施粥现场的秩序冲突），不再抢主角食物；②小孩/大人两轮保留，但改为"劝/给/强硬"三选；③**不还手**→ 被推倒 + 力竭（仍走 `army.rescue.faint`，保留杀/救抉择）；④强硬 → 村民敌对波 → 打赢力竭、打输被打晕（与现状同构）；⑤新增事实 `story.s02.crowd.order`（`orderly`\|`chaos`）；⑥追杀段 HP 归零改为**被捕**（`playerArrested`），押解途中被受惠村民救出 → 回到举事 |
| 删/改 | 改 4 个 dialogue 文案与 2 个 branch；**不删步骤**；删 `begPacifist` 的 `takeReward`（不再抢食物）；新增 1 个事实 + 1 个被捕分支 |
| 对后续影响 | 诬告证据多一条 `riot`（"聚众殴斗、秩序大乱"）；`crowd.order=chaos` 会降低村民好感；杀/救抉择、`story.s02Rescued` 全不动 |
| 代价 | **纯数据**（对话/分支/1 事实）；被捕分支若要做押解演出需 1 个新 region + 1 段对话，仍属数据层 |

#### 方案二：替换为新桥段（官兵"查妖"打砸粥棚）

| 项 | 内容 |
|---|---|
| 改动 | 删掉整条乞讨链，替换为**官兵第一次出场**：`porridge` 之后 → 县兵冲进粥棚、打翻粥锅、抓走村民 → 主角阻拦被**打倒**（仍走 `army.rescue.faint`，保留杀/救抉择）→ 黄巾小队入画、官兵退走 → 杀/救抉择 → 召见。后续符水/铜钱剑/诬告/追杀不变 |
| 删/改 | 删 8 个 `beg*` 步骤 + 4 个 dialogue + 4 个 NPC 组（`S02-beg-children*` / `S02-villagers-calm` / `-hostile`）；新增 2 个 dialogue（`dialogue.s02.officerRaid` / `.officerRaidAfter`）+ 3 个步骤 + 1 个县兵组（**复用 §6 的 `enemy.s02_county_*` 定义**） |
| 对后续影响 | 官府作为反派的**首次亮相提前**，诬告时玩家已认识县兵 → 因果更顺；杀/救抉择不动；`story.s02Rescued` 语义不变；可新增 `story.s02.officerRaid` 作为诬告的附加罪状（"阻挠官差"）；食物不再被抢，早期资源更宽松 |
| 代价 | **纯数据**（新 dialogue/placement/quest steps，复用 `waveCleared` 与既有 enemy 定义）；"抓人"演出首版用 despawn 表现即可，无需新代码 |

#### 方案三：合并进追杀段（删掉独立两段）

| 项 | 内容 |
|---|---|
| 改动 | 删掉乞讨链与"被打晕"的可玩段：进村 → `spawnInitial` 旁白 + `porridge` → 召见 → 符水/铜钱剑 → 诬告 → 追杀（HP 归零 → **被捕** → 押解 → 乡民救出 → 举事）。杀/救抉择降级为**黑屏旁白过场**（10 秒概括"你昏倒在村口，张角救了你"），不再有可玩触发 |
| 删/改 | 删 8 个 `beg*` 步骤 + 4 个 dialogue + 4 个 NPC 组 + `army.rescue.faint` 的玩法触发点；杀/救抉择改为 `sceneEnter` 直接 `startDialogue` + 写 `story.s02Rescued`；新增"被捕/押解/被救"3 步 |
| 对后续影响 | S02 首段从 8 步压到 2 步，时长缩短约 5–8 分钟；**丢掉"给物品"与"可打赢的小战斗"两种体验**，需在符水/追杀段补回；杀/救抉择从可玩变过场，`S02ArmyRescueFlow` 的救援流程**不再被剧情调用**（只剩系统级复用） |
| 代价 | 数据为主，但**要动杀/救抉择入口**（`sceneEnter` 直接推进 vs 现在由 `army.rescue.faint` 驱动）——若走纯数据需确认 `sceneEnter` 能直接 `startDialogue` + `commitFact`；否则是**轻量代码**改动 |

### 12.5 推荐：方案二

**理由（按权重）**：

1. **反派统一**：官府从"查妖打砸"→"诬告"→"追杀"→"围剿"是同一条升级线，第一次暴力冲突就指向主线矛盾；方案一让饥民继续当第一波冲突，与"张角济民被诬"的主题相反。
2. **保住关系基石**：杀/救抉择（张角杀/救主角）与 `story.s02Rescued` 完全不动，改动只在"谁把主角打倒"。
3. **因果更顺**：玩家先见过官兵打人，诬告时不需要额外解释"官府为什么坏"；还能多给一条"阻挠官差"的既成罪状。
4. **代价最低**：纯数据，复用 `enemy.s02_county_*`（§6 已定义）与 `waveCleared`，不新增系统。
5. **顺带解决两处别扭**：饥民抢义士的道德冲突消失；"给物品"教学由符水交互承担。

**次选**：方案一（改动最小、可快速落地，但"饥民抢粥"仍与济民主题别扭）。
**不建议**：方案三（压缩最狠，但丢掉可玩杀/救抉择与两种体验，且要动杀/救抉择入口）。

### 12.7 方案二：玩家视角逐步流程（从进 S02 到举事之后）

> 按玩家实际经历顺序写。每段四件事：**看到什么 / 要做什么 / 能怎么选 / 做完世界变了什么**，
> 末尾一句"这段想让你感觉到什么"。

#### ① 开场：荒村

- **看到**：山道尽头一个破败村落。田埂上有人跪着挖树根，妇女剥草皮，几个孩子蹲在路边。
  旁白：**「山道旁的荒村炊烟零落。田埂上有灾民跪着挖树根，妇女们剥草皮充饥。」**
- **要做**：往村里走。没有目标提示，只有环境叙事。
- **可选**：无分支，纯粹是"看见"。
- **世界变化**：`story.s02.spawned` 写满；村民组 `S02-villagers-calm` 就位；粥棚（`S02-prop-porridge`）已存在。
- **想让你感觉到**：这里不是关卡入口，是一群快饿死的人住的地方。

#### ② 粥棚：施粥

- **看到**：村中空地上的大锅，热气；张角与几个黄巾装束的人在忙。
- **要做**：走到粥棚交互（任务目标「支锅施粥赈济灾民」）。
- **可选**：无分支（目标步骤，必须完成）。
- **世界变化**：`story.s02.porridge.laid` 写入；粥棚烟火/光晕亮起；村民开始在锅前排起队。
- **想让你感觉到**：张角是在**救**人，不是在山里练邪术——先把"善"立起来。

#### ③ 【新增第 1 步】官兵"查妖"：打砸粥棚

- **看到**：村口进来七八个县兵（刀盾/枪/弓），为首一名县尉，甲胄不整但刀是亮的。
  他踢翻一口陶瓮，喊：**「谁让你们在此聚众施药？」** 两名兵把排队村民推开，锅被掀翻。
- **要做**：没有任务提示，玩家可自由行动（可以站在一边看，也可以动手）。
- **可选**：三选，**都不改主线走向**：
  1. **上前阻拦**（推荐路径）→ 进④；
  2. **站远处不动** → 村民被拖走一个，旁白「你听见孩子在哭」，仍进④（主角随后被卷入）；
  3. **试图交涉**（对话选项）→ 县尉一句「刁民也配说话」，直接进④。
- **世界变化**：`S02-officer-raid` 组入场；队列村民进入"惊慌"姿态（`S02-villagers-calm` 原地抖动/后退）；
  粥锅翻倒（`S02-prop-porridge` 切破损态）；写 `story.s02.officerRaid`（诬告段可引用的罪状）。
- **想让你感觉到**：**善举第一次撞上官府**——不是仇恨，是"凭什么"。

#### ④ 【新增第 2 步】主角阻拦被打倒

- **看到**：镜头收窄到主角与县尉之间，县尉抬手，两名刀盾上前。
- **要做**：这里**不进入战斗**（不是可打赢的战斗），是一段短过场 + 一次**可选的反抗输入**。
- **可选**：
  - **出手**（按键/交互）→ 主角打翻一名兵，随即被刀背砸中后颈 → 黑屏；
  - **不出手**（等 3 秒）→ 被一棍打在膝弯跪下 → 黑屏；
  - 两条路**结果相同**，但台词不同（出手：「你还敢还手？」／不出手：「倒是个识相的。」）。
- **世界变化**：`army.rescue.faint` 被调用（**与现状同一命令**）；主角进入 plotDowned；玩家失去操控。
- **想让你感觉到**：你**打不过官府**，但你没有跪下——两种选择都保住了体面。

#### ⑤ 黑屏：黄巾小队入画 → 张角杀 / 救

- **看到**：黑屏 2 秒，车轮碾地声由远及近。画面回来：**张角带着二十名黄巾信众、推着几辆装满粮食的木车**
  沿山道行来（`S02-army-column` + `S02-believer-train` 入画，`army.march` 沿 `path.s02.column.entry` 行军），
  官兵见状退走（不接战）。军队抵达村口（`armyMarchArrived`）后斥候来报，张角走到倒地的主角面前，沉默片刻：
  **「乱世之人，死生各由天命。这个人——怎么处置？」**
- **要做**：**杀 / 救** 二选一（`dialogue.s02.prologue`，机制完全不变）。
- **可选**：
  - **杀** → 结局「乱世草芥」（既有分支，不动：写 `story.s02.judgement.kill` + `ending.command` 提交 `chaos-weed`）；
  - **救** → 写 `story.s02.judgement.save` + `army.rescue.begin`（`regionId: S02-camp-rescue`，目标点 620,350），
    士兵抬担架把主角抬进村中救援点，解锁 `task.s02.rescue`（搬运教学 → 苏醒 `dialogue.s02.awakening` → 写 `story.s02Rescued`）。
- **世界变化**：`story.s02.beg.armyArrived` 写入；选救后 `story.s02Rescued` 写入、`task.s02.rescue` 可接；县兵组 despawn；`S02-officer-raid` 清场。
- **想让你感觉到**：你死里逃生，救命的人刚刚还在犹豫要不要杀你——**乱世的善意是有代价的**。

#### ⑥ 杀/救抉择之后：回到村落

- **看到**：你在粥棚旁醒来（与现状同一救援苏醒点）。村民围在旁边，有人递水；张角站得稍远。
  旁白：**「那伙官差走了。你的命，是这些人捡回来的。」**
- **要做**：走动、和村民对话（可选寒暄），走向张角。
- **可选**：可选择先和受惠村民说话（2~3 句旁白，给"村民好感"的感知），也可直接找张角。
- **世界变化**：主角恢复操控；`S02-villagers-calm` 恢复常态；粥棚修复（若③选了站远处，锅仍是破的，
  由村民补好，一句旁白带过）；村民对主角的态度从"陌生人"变"恩人/同路人"。
- **想让你感觉到**：**你欠这里一条命，而这里的人把你当自己人**——这是后面"替他们反"的情感账户。

#### ⑦ 召见：张角交托

- **看到**：张角在粥棚边等你（`acceptSummonsInteract` 交互点）。
- **要做**：走近触发 `dialogue.s02.zhangjiaoSummons`。
- **可选**：可拒绝一次（对话有"我再想想"选项），但最终必须接受才推进。
- **世界变化**：`story.s02.summons.accept` 写入；`acceptSummons` 目标完成；开启符水/铸剑两个交互点。
- **想让你感觉到**：你不是被招募的兵，是被**托付**的人。

#### ⑧ 善举一：散符水（N1）

- **看到**：粥棚旁多了一口陶瓮（暖黄微光），张角把一包符灰递给你：
  **「这些都是苦命人……你替我递过去。」**
- **要做**：走到陶瓮交互，每次递一碗给一名村民。
- **可选**：递几碗随你（总量上限 50 碗）；符灰用完时张角会说「今日就到这里吧」。
- **世界变化**：每碗 `story.s02.boonWater.count +1`、`stock −1`；喝过的村民姿态变化（精神起来）；
  提示「已施 X 碗」；`story.s02.boonWater.servedIds` 记录受惠者。
- **想让你感觉到**：**做善事本身**——没有奖励数字，只有人喝下去之后的呼吸。

#### ⑨ 善举二：发铜钱剑（N2）

- **看到**：铸剑台上一串串用铜钱缠成的小剑（钝得切不开皮），张角：
  **「给他们防野兽。记住，这只是个念想。」**
- **要做**：把剑一把把交到村民手里（交互，共 7 把）。
- **可选**：可以先发、也可以先不碰（但不发到 3 把就不会触发诬告）。
- **世界变化**：`story.s02.coinSword.given +1`（封顶 7）、`.forged = 7`；村民腰上出现小剑附件；
  提示「你把一柄铜钱剑交到 X 手里」。
- **想让你感觉到**：**你发的是护身的钝器，不是兵器**——这个认知差会在下一段被官府扭过来。

#### ⑩ 诬告：县尉当众宣读罪状（N3）

- **看到**：县尉带着兵又回来了，这次人更多。他站在村中空地上，摊开一卷竹简，当众宣读：
  - 「聚众二百余口，昼夜不散——这是要做什么？」→ 旁白：**「你只是把粥一碗碗递出去。」**
  - 「以符水惑众，称能治疫——妖言也。」→ 旁白：**「你只是把药汤递给咳血的孩子。」**
  - 「私铸兵刃，遍授村夫——这是要反。」→ 旁白：**「那剑钝得切不开皮，是给他们防狼的。」**
  - （若施过粥）「散粮收买人心，钱粮从何而来？」→ 旁白：**「粮是张角从山里背下来的。」**
- **要做**：听（对话不可跳过第一遍的罪状部分，之后可快进）。
- **可选**：对话末尾可争辩一次（三个选项：辩"符水治病"/辩"剑是防兽"/沉默），
  **无论哪条，县尉都回一句"拿下"**——争辩只改变村民的反应（替你说话/低头不敢言）。
- **世界变化**：`story.s02.accused` 写入；`accusation.evidence` 数组按实际做过的事生成；
  `S02-pursuit` 组入场；`S02-pursuit-zone` 战斗区生效；`S02-accusation-zone` 关闭。
- **想让你感觉到**：**每一句罪状旁边都并排放着你真实做过的事**——荒谬感不是靠台词喊出来的，
  是靠"你亲眼知道自己做了什么"。

#### ⑪ 官兵追杀：打，还是走（N4）

- **看到**：县尉拔刀，九名县兵展开成扇形，把粥棚围住。村民往后退。可选提示：
  **「你要打，还是走？」**
- **要做**：二选一，这是本段唯一会影响后续数值的选择。
- **可选**：
  - **打**：进入真实战斗（县尉 + 4 刀盾 + 3 枪 + 1 弓；10 秒后第二波 4 刀盾）。
    打赢 → `pursuit.killed`；被打死 → 见下"打输"。
  - **走**：从西侧山道离开战斗区 → `pursuit.fled`，不刷第二波。
  - **打输（HP 归零）**：不弹复活窗，短黑屏「你被打倒在地，耳边只剩铜钱剑落地的声音」→
    张角把你拖走 → 按"逃"结算（`outcome:'flee'` + `playerDowned`）。
- **世界变化**：
  - **打**：`faction.county` 声望 −25；村民好感 +10；`raid.urgency='high'`（围剿首波 +2 兵、提前一夜）；
    地上留下官刀/尸体（可搜刮，少量铁）；村民开始叫你"恩公"。
  - **走**：官府声望 −10；村民好感 −5；官兵**放火烧村**（`S02-village-burned` 地贴/火光），
    `raid.urgency='normal'`；张角台词：「他们把村子点了……我们还能去哪？」
  - 两路都写 `pursuit.outcome`。
- **想让你感觉到**：**打是血性，走是活命，都要付账**。没有"正确答案"。

#### ⑫ 被迫反：退无可退（N5）

- **看到**：张角站在冒烟的粥棚/官刀之间，很平静地说：
  「今日不反，明日无葬身之地。」（打）／「村子没了，人还在。反了吧。」（逃）
- **要做**：确认（一次对话）。
- **可选**：无分支（这是剧情节拍，不是选择）。
- **世界变化**：`story.s02.revolt.confirmed` 写入——**征兵入口从此解锁**（此前是灰的/不出现）。
- **想让你感觉到**：造反不是野心，是被推到墙角。

#### ⑬ 征兵：一次成军

- **看到**：村中竖起招众旗（或征召处雏形）。喝过符水、拿过铜钱剑的村民**主动**站到旗下——
  不再是一个个来问"管饭吗"，而是"我跟你去"。
- **要做**：走到旗下**交互一次**（原 5 次×10 的计数已废弃）。
- **可选**：无算法式分支；但台词按前段结果分档（打→"咱们杀了官，回不了头了"；逃→"家都烧了"）。
- **世界变化**：`story.s02.recruit.done` 写入（旧键 `s02RecruitCount` 一次性写满 50 保持兼容）；
  `S02-army-recruits` 组一次出兵（黄巾军）；编组/小队组件注入。
- **想让你感觉到**：**这不是募兵，是投奔**——你之前做的善事，现在变成了人。

#### ⑭ 检阅：张角看队伍

- **看到**：一队刚成军的黄巾站在空地上，队形歪但眼睛亮。张角走了一圈，没说话，只是点头。
- **要做**：看（纯演出，可跳过）。
- **世界变化**：无新事实（`after.recruit.2`），只为举事蓄势。
- **想让你感觉到**：**人有了**——下一步只能是举旗。

#### ⑮ 举事：村落转军营

- **看到**：张角登高（旗台/土台），举旗。台词按 `pursuit.outcome` 分两版。
  随后：旧村落地物与乞讨村民 **despawn**，六类建筑**在同一个村子里**落成——
  **铁匠铺**（炉火亮起）、**征召处**（旗+桌）、**粮仓**（满仓，可见粮袋）、
  **兵营/出兵点**（军字旗）、**栅栏**（沿村口围一圈）、**军营大门**（可开合）；
  营地地贴覆盖原土路，篝火/烟尘/旗号亮起。
- **要做**：看（过场约 8~12 秒），可跳过。结束后恢复操控。
- **可选**：无。
- **世界变化**：`story.s02.uprising` 写入；`S02-village` 组 despawn；
  `S02-camp-buildings` 组 spawn（六类建筑 + 栅栏 + 大门）；
  `construction.s02.smithy / .recruitPost / .granary` 就位；`S02-building-barracks` 出兵点可用；
  张角换装/旗号变化。
- **想让你感觉到**：**同一个地方，一夜之间变了性质**——不是换地图，是"这里现在是我们的营"。

#### ⑯ 举事之后：军营开放状态

- **看到**：营地。四个可交互点 + 可看出兵点：
  1. **铁匠铺**——修理装备（首版）/ 后续锻造入口；
  2. **征召处**——后续补充兵员（首版只显示"已征满"或留作 S03 入口）；
  3. **粮仓**——查看存量（首版只读，提示"粮草尚足，可支半月"）；
  4. **兵营/出兵点**——显示当前编成（谁在队里、几队）；
  5. **栅栏/大门**——可开合，围剿时是防线。
- **要做**：自由探索，可先去扎营点推进主线（`camp`）。
- **可选**：与四个交互点对话/查看（都不阻塞主线）。
- **世界变化**：**乞讨相关的一切都不再存在**——小孩/大人 NPC、乞讨对话、抢夺逻辑、
  被打晕分支全部随 `S02-village` 组 despawn；`S02-villagers-calm/hostile` 不再被引用；
  村民变成"营地居民"（可保留少量营地 NPC 做氛围，但不再有乞讨交互）。
- **想让你感觉到**：**这里从"求人活命的地方"变成了"能打回去的地方"**——
  而且你亲手参与了它变成这样。

#### ⑰ 之后：扎营 → 围剿 → 南下（保持闭环）

- 扎营（`camp`）→ 当夜（`campComplete`，含"粮草充足"一句）→ 官兵围剿（远程接管张角，
  打/撤都不判负）→ 第二波 → 胜利 → 击退对话 → 拾荒者支线 → 南下 S09。
- **与方案二的衔接点**：围剿首波规模读 `pursuit.outcome`（打 → +2 兵、提前一夜；逃 → 正常）。

### 12.8 方案四（新增）：替民受缚 · 囚车截停

> 目标：换掉"主角被一拳打倒"这个廉价解法，让**倒下这件事本身有主动性**，
> 同时让杀/救抉择"杀/救"获得更强的动机。

#### 设计

官兵查妖打砸粥棚（同方案二③）→ **县尉要抓人抵罪**（抓的是村民，不是主角）→
**主角主动站出来**：「符水是我散的，剑是我铸的，抓我。」→ 县尉把主角上绑带走（**主角全程清醒**）
→ 押解队伍走村外山道 → 兵卒途中拷打/推搡，主角在冲突中被打晕（**黑屏，不给战斗**）→
张角的小队在山道**截停囚车**（官兵弃车而逃）→ 张角掀开车帘：里面是个被打得不成样子的陌生人，
而这个人**见过他的部队袭击官差** → **杀（灭口）还是救（留下一个证人）** → 杀/救抉择（`dialogue.s02.prologue`）。

关键差异：**杀/救抉择的"杀"第一次有了硬理由**（灭口），不再只是"乱世里少一个累赘"；
"救"第一次有了硬代价（多一个知道你袭官的人）。主角也从"受害者"变成"主动顶罪的人"。

#### 与方案二的对比

| 维度 | 方案二（阻拦被打倒） | 方案四（替民受缚·囚车截停） |
|---|---|---|
| 主角倒下前的行为 | 阻拦 → 被打倒（被动） | **主动顶罪 → 被押走 → 押解冲突中被打晕**（主动） |
| 玩家感受 | "我打不过官府"（无力感） | "我替他们扛了"（担当感）+ "我是不是要死了"（悬念） |
| 杀/救抉择 杀/救 动机 | 张角面对一个倒地陌生人：杀=省事，救=心善 | 张角面对一个**见过自己袭官**的陌生人：**杀=灭口，救=冒险** ——两难更硬 |
| 杀/救抉择衔接 | 成立（同一对话、同一位置） | **成立**：囚车截停后用一段黑屏旁白"张角把人抬回村中救援点"，杀/救抉择仍在现有救援点播放（不改位置） |
| 村民求情 | 无（村民只是旁观） | **有**：主角被绑走时村民下跪求情/递食物 → 举事时"一次成军"的民意基础**可视化** |
| 与诬告段的关系 | 诬告是第一次"官府定性" | 诬告同时**先抓人再定罪**，更贴近"构陷"逻辑；且主角已顶过罪，诬告词可引用"此人已自认" |
| 追杀段衔接 | 主角从村中被围 | 主角被救回后，官兵卷土重来（"抓的人被劫走"→ 必须灭口），**追杀动机更强** |
| 实现代价 | 3 步 + 2 对话 + 1 县兵组（纯数据） | 3 步 + **1 段押解演出**（1 个 region + 2~3 句黑屏旁白 + 1 次 spawn/despawn 换位）+ 2 对话 + 复用县兵组；仍以数据为主，**只多一段不接战的过场** |
| 对昏迷流程 | 需要 `playerSpecialFaint` 新增 `rescueType:'officerRaid'`（若是战斗倒下） | **不需要新分支**：押解是剧本脚本，直接调 `army.rescue.faint`（与现状同款）；只有追杀段 HP 归零仍需 §6.4 的 `pursuit` 分支 |
| 风险 | 无 | ①押解段的"换位"若用 spawn/despawn 会有 1 次黑屏成本（可接受）；②杀/救抉择的"陌生人"文案需微调 2~3 句（"这人是官差押的"） |

#### 推荐（修订）

**改推方案四，方案二降为次选。**

理由：
1. **杀/救抉择从"顺手"变成"两难"**：方案二里张角杀一个倒在地上的陌生人缺乏动机；方案四里"这人是目击者"
   让杀/救第一次有了对等的分量——这是**杀/救抉择自身的升级**，不只是"换个人打倒主角"。
2. **主角获得主动性**：顶罪是玩家按下的选择，不是剧本替玩家挨打；这与新主线"善举被诬"的主题同构
   （**你主动承担，反被当成罪证**）。
3. **民意基础可视化**：村民下跪求情 → 举事时"主动站到旗下" → 一次成军不再像凭空刷兵。
4. **实现代价几乎不增**：只多一段**不接战的黑屏过场**，不需要新的战斗、不需要新的 `playerSpecialFaint` 分支；
   反而比方案二**少**一个 `rescueType` 分支。
5. **追杀动机更顺**：从"官府来抓人"升级为"抓走的人被劫走，必须灭口"，官兵第二次来的理由更硬。

**代价与前提**：需确认杀/救抉择触发点可以在"押解过场结束"后正常播放（现有救援点不变，用黑屏旁白衔接）；
若杀/救抉择绑定在特定区域触发，则需把该区域设为"过场结束后强制播放"，仍属数据层配置。

**保留意见**：若用户希望**完全不出现"被打晕"**，则只剩"改写这段杀/救抉择"这条路（把杀/救改成
"张角要不要收留一个清醒的陌生人"），但那会动到杀/救抉择这个既有 setpiece 的核心，风险显著更高，不建议首版做。
