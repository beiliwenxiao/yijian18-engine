# S02 荒村乞讨 → 军队救援 → 扎营 → 围剿 → 行军 设计

> 状态：设计稿（待评审）· 2026-10-27
> 引出：用户评审现有 S02 任务链判定「明显有错漏」，提出完整重设计。
> 定位：S02 全流程重构——荒村乞讨冲突、张角军队路过救援（保留担架玩法）、军团扎营、官兵围剿战（操控张角）、三段行军入 S09。

---

## 1. 用户原话（2026-10-27，需求权威）

1. 应该先进入灾民乞讨的环节（现在没有）。灾民乞讨，灾民挖树根，吃草皮。
2. 主角进入，有小孩乞讨，主角给了果子，出现更多小孩乞讨。主角可以选择给（5 个果子）或者不给。**无论给不给，小孩都散去**。
3. 这时，出现更多大人也乞讨。主角选择给或不给：
   - 选择给（20 个果子或 5 块狼肉），则乞讨者抢夺主角身上的物品。
   - 选择不给，则乞讨者开始攻击主角。
4. 这时候给出选项：**不还手 / 还手**。
   - 不还手：身上食物类物品被抢光，被打昏迷，NPC 仍然显示绿色血条，无法攻击。
   - 还手：身上物品不变化，NPC 变红色血条，可以攻击。**打赢旁白：力竭昏迷；打输旁白：被打晕了**（殊途同归进昏迷）。
5. 之后，一小队（**50 人**）张角军队路过，才出现询问是否救援主角的事件。
6. 询问和救援完成后，**控制军队扎营**。
7. 这时候遇到**官兵围剿**（可查历史，选哪个名将来围剿）。控制**张角**带领军队抵抗围剿。
8. 胜利后**不能直接穿越到 S09**，而是跟随军队穿过**森林、高原、山地**，之后才到达 S09 营地。

## 2. 现有链错漏对照（2026-10-27 勘察）

## 3. 历史考据：围剿将领定案

**推荐：卢植（北中郎将）**，理由：

1. **史实对位最正**：中平元年（184 年）起义爆发后，汉灵帝拜卢植为北中郎将、持节，专讨张角——连战破黄巾、斩获万余，张角等**退保广宗**；卢植筑围凿堑、造云梯，垂当拔城（后因不贿宦官左丰被谗，槛车征还，董卓接替复败，再改皇甫嵩）。本关「官兵围剿→张角军向广宗转移」与卢植压境的史实时间线严丝合缝，且 S09 正是广宗大营。
2. **不与后续场景撞车**：S03 颍川（波才）、S04 长社（皇甫嵩火计）已占用颍川线；南阳归朱儁。冀州广宗线归卢植，各线不重复。
3. **名将成色与后续剧情钩子**：卢植是儒将（刘备公孙瓒之师）、正面形象，被宦官构陷囚车征还的史实可作为后续剧情钩子（黄巾喘息的窗口）。

本关实际 BOSS 两个方案（决策点①）：
- **A. 卢植亲征本关**——名将正面出场，卖点强；但史实上卢植围的是广宗城，S02 在行军路上，提前遭遇略早。
- **B. 卢植压阵，部将出战**——敌将为卢植麾下先锋（史实部属可选：护军司马**傅燮**、将领**宗员**、钜鹿太守**郭典**），卢植在本关对话中出镜不下场。史实更严谨，名将形象留给后期广宗决战。

## 4. 新流程分镜（五幕）

```
第一幕 荒村惨状 → 第二幕 乞讨冲突 → 第三幕 军队路过救援
→ 第四幕 扎营与围剿战 → 第五幕 三段行军 → S09
```

### 第一幕：荒村惨状（进入场景即触发）
- sceneEnter → 旁白：山道旁荒村炊烟零落，灾民在田埂挖树根、剥草皮充饥（灾民 NPC 群蹲坐/沿树根点缓步移动——AI patrol 现成能力）。
- 环境呈现用 despawnPlacements/spawnPlacements + showTip + 灾民巡逻，零门槛进入。

### 第二幕：小孩乞讨 → 大人乞讨 → 冲突
1. **小孩乞讨**：小孩 NPC 靠近 → 对话乞讨 → 给果子 → 又来更多小孩 → 选择：
   - **给**（扣 5×resource.wild_berry 野果）→ 小孩散去；
   - **不给** → 小孩散去。
   （两分支殊途同归：小孩都散去，进入大人乞讨。）
2. **大人乞讨**：灾民大人围上 → 选择：
   - **给**（20×野果 或 5×resource.raw_wolf_meat 狼肉，二选一）→ 交出后众灾民失控哄抢，主角身上**食物类物品被抢光**；
   - **不给** → 灾民开始攻击主角 → 弹出选择：**不还手 / 还手**。
     - **不还手**：食物类物品被抢光，被打昏迷；村民保持绿血条（friendly），玩家无法攻击（despawn hostile 不发生，villagers-calm 组原样）。
     - **还手**：身上物品不变；村民切红血条可攻击（despawn calm 组 + spawn hostile 组——现有双组切换模式现成）。**打赢** → 旁白「力竭的你扶着断墙滑坐在地，眼前一黑」；**打输**（玩家 HP 归零）→ 拦截死亡弹窗，旁白「被打晕了」——两分支殊途同归进昏迷。
3. 昏迷 = 主角 plotDowned（现有 army.rescue.faint 命令复用）。

**食物类物品清单**（被抢光判定范围）：resource.food（干粮）、resource.wild_berry（野果）、resource.apple、resource.raw_wolf_meat（生狼肉）、resource.raw_rabbit_meat（生兔肉）、food.roasted_wolf_meat（烤狼肉）、food.roasted_rabbit_meat（烤兔肉）。

### 第三幕：张角军队路过（50 人）→ 救援
1. 昏迷后黑屏过渡 → **50 人黄巾小队从场景边缘行军入画**（军队沿路径移动到村口停下——军团移动下令能力）。
2. 黄巾斥候发现昏倒的主角 → **现有 dialogue.s02.prologue（张角二选一：杀/救）原样保留**，仅触发源从「pacify 昏迷立即」改为「军队抵达后」。
3. 选杀 → 结局 chaos-weed（不变）。
4. 选救 → 现有担架救援链保留（task.s02.rescue + army.rescue.begin + 教程×2），担架兵从 50 人小队出 2 名（CARRY_MIN_CARRIERS=2 满足）。

### 第四幕：扎营 → 官兵围剿战
1. 救援抵达营地（enterRegion S02-camp-rescue）→ army.rescue.awaken → **dialogue.s02.awakening 苏醒对话保留**（张角赠符水、自我介绍）。
2. **控制军队扎营**：军团特殊命令「扎营」首个落地（army-command-design §2.2 特殊命令清单原有项）——全军移动到营地坐标、切原地防守姿态、生成篝火/帐篷装饰物、提交 story.s02.camp.laid、显示命令倒计时（复用现有倒计时表现）。
3. **官兵围剿**（卢植部先锋突袭营地）：
   - 敌军 placement 分波进场（官兵前锋 → 官兵主力）。
   - **玩家操控张角**带军迎战：视角接管切换到张角武将实体（主角退为随军伤员/观战），军团指挥 M5 全套可用（escort 跟随/意图右键/姿态/Tab 编组）。
   - 胜利（waveCleared）→ 旁白 + story.s02.raid.repeled。

### 第五幕：三段行军 → S09
1. 围剿胜利后张角下令转移广宗——**删除现有直接传送**（task.s02.summons 的 travel 步骤 + S02-zone-s09-exit 出口改语义）。
2. 三个行军过场场景（决策点④）：**林道（森林）→ 高原 → 山径（山地）**，每段：
   - 军队行军队列 + 玩家（张角）随行 + 段内一个事件（行军对话/小遭遇/景物旁白）；
   - 段尾转场进下一段；
   - 第三段尾抵达 S09 广宗大营 → 衔接现有 trg_s09_opening_dialogue 与入伍线（task.s09.joinYellowTurban）。
3. 军队跨场景搬运：每段场景按 spawnWhen(storyState) 门控 spawn 该军队 placement，段尾 despawn（现有流式/门控机制复用）。

## 7. 分期实施

| 期 | 内容 | 验证 |
|----|------|------|
| M1 | 荒村乞讨链重做（第一、二幕：惨状呈现/小孩/大人/抢夺/不还手/还手/打输拦截） | 五条分支全可走：小孩给/不给、大人给/不给+不还手/还手、打赢/打输殊途同归昏迷；物品扣减与抢光正确 |
| M2 | 军队路过+救援（第三幕：50 人行军入场、prologue 挪时序、担架救援保留） | 昏迷→军队入画→抉择→救援全链；杀分支结局不受影响 |
| M3 | 扎营+围剿战+操控张角（第四幕：army.camp、possession 切换、官兵波次战） | 扎营倒计时/装饰/事实就位；张角操控手感、波次战胜利判定；打输分支 |
| M4 | 三段行军+S09 衔接（第五幕） | 三段全走通到 S09；存档/读档在行军中途可恢复；旧 summons 传送拆除无回归 |

每期交付跑场景核心回归 + 实机冒烟；M1 可独立先行（不动救援链）。

## 8. 决策点（待拍板）

| # | 决策 | 建议 |
|---|------|------|
| ① | 围剿敌将：A 卢植亲征 / B 卢植压阵+部将（傅燮/宗员/郭典）出战 | B——史实严谨，卢植留广宗决战 |
| ② | 操控张角：A 真实 possession 切换（引擎新能力，M3 大项）/ B 主角带队+张角 NPC 协同（省） | 按用户原话取 A |
| ③ | 50 人军队：全实体 / 可见行军队列 12-15 实体+编成数字「50」 | 先全实体实测性能，安卓卡则降级队列方案 |
| ④ | 行军三段载体：A 世界格新场景（改 grid terrain）/ B 离格子子场景（S01-C01 模式） | B——不动世界网格与流式，S02(7,4)→S09(9,6) 之间是黄河块，改地形反而穿帮 |
| ⑤ | 「给」分支被抢范围：食物类全抢 / 部分抢（如抢一半） | 全抢——世道残酷主题（好心招祸，反抗保命），且与「不还手」结果对齐 |

| ⑦ | 随军转移任务：改造 task.s02.summons / 新增 task.s02.march | 改造 summons（少一条任务，步骤=扎营→围剿胜利→抵达 S09） |
